# Dictionary Search

Vocabulary for dictionary search results and their textual content.

## Language

**Image text mapping**:
A user-defined association between an image in a dictionary and the equivalent text used when copying a result entry.

**Image omission rule**:
A user-defined instruction to omit a particular dictionary image from copied text without reporting it as unresolved.

**Image copy rule**:
A rule that specifies how a dictionary image is handled when copying a result entry: replace it with equivalent text or omit it deliberately.

**Inactive image copy rule**:
A retained image copy rule that does not apply to the currently installed revision of its dictionary.

**Unresolved image**:
An image in included dictionary content whose equivalent text or illustrative role cannot be established. Its omission is reported alongside the available copied text.
